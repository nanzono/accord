# 公開記録

外から確かめられる公開の成果物を、1 件 1 ブロックで持つ。各件は「ID」の行を持ち、機能の裏づけは
この ID で 1 件を指す。URL を持たないもの（紙の媒体など）は「なし」と書く。由来の節は、その中身の
元になった職歴の枠か受託案件の ID で、無ければ「なし」と書く。

- 出所: 発表の資料と、主催が出した開催の記録
