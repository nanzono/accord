# パッケージ定義

機能を束ねて、誰に売るかを定めた売り物の単位。いま何を前面に出すかは、この文書ではなく
`positioning.md`（売り方の決め）が持つ。各束は「ID」の行を持ち、決めと提示物はこの ID で束を指す。
束ねる機能は `capabilities.md` にある機能の ID に限り、複数あるときは半角の `/` で区切る。
