# 同梱のサンプルについて

`source/` の中身は、すべて架空の人物と架空の案件である。実在の人物・会社・媒体とは関係が無い。
accord のテストと、初めて動かすときの確かめは、このサンプルの上で走る。

## 架空の名前と、実在しないことの確かめ

名前を決める前に Web で検索し、同じ名前の会社や知られた人物が出ないことを確かめた。
確かめた日はすべて 2026-09-16 である。

| 使っている名前 | 何として使うか | 確かめた結果（2026-09-16） |
|---|---|---|
| 霧沢 千景（きりさわ ちかげ） | 経歴の持ち主（本人） | 同じ名前の人物・会社は出なかった。似た響きの創作上の人物名は出たが、同じ名前ではない |
| 株式会社テラミナ物流 | クライアント 1 社目 | 「テラミナ」という名前の会社は出なかった（「テルミナ」という別の名前の会社は実在する） |
| 株式会社ユキノハ化成 | クライアント 2 社目 | 「ユキノハ」という名前の会社は出なかった |
| ナギサ書房 | クライアント 3 社目 | 同じ名前の出版社・書店は出なかった |
| tsukikusa | 媒体 1 つ目 | 同じ名前の求人・転職の場は出なかった |
| nagiho | 媒体 2 つ目 | 同じ名前の求人・転職の場は出なかった |

掃いた範囲は Web 検索の結果の 1 ページ目である。登記の一覧（法人番号の検索）そのものは当たっていない。

なお、設計文書が媒体の名前の候補に挙げていた `harbor` は使わなかった。検索の結果、日本で
働く人向けの同じ名前の場と、同じ名前の会社が実在したためである（候補は「後で覆してよい前提」として
置かれていたので、覆した）。

## 中身

| ファイル | 何の正本か |
|---|---|
| `accord.toml` | 設定の見本。正本の置き場と、固有の語彙（媒体の名前・機能の分類の 5 節・仮説の状態の語） |
| `source/positioning.md` | 売り方の決め。1 決め 1 ブロックで積む |
| `source/packages.md` | パッケージ定義 |
| `source/capabilities.md` | 機能の台帳。節の見出しが分類 |
| `source/career.md` | 職歴の枠 |
| `source/engagements.md` | 受託案件 |
| `source/resume_ledger.md` | 職務経歴書の台帳 |
| `source/presentations/` | 提示物。媒体ごとのディレクトリに置く |

この正本は違反を 1 件も含まない整った状態にしてある。違反を仕込んだ形はテストが
一時的な写しの上で組み立てるので、この中身は書き換えない。
