# パッケージ定義

機能を束ねて、誰に売るかを定めた売り物の単位。いま何を前面に出すかは、この文書ではなく
`positioning.md`（売り方の決め）が持つ。束ねる機能の名前は `product/features.md` にある名前に限る。

このファイルには、パッケージでない節も置いてある。パッケージとして読む節は、設定ファイルの
`[reading.packages]` の `skip_headings` が、読まない見出しを名指しして決める。
