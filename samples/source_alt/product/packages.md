# パッケージ定義

機能を束ねて、誰に売るかを定めた売り物の単位。いま何を前面に出すかは、この文書ではなく
`positioning.md`（売り方の決め）が持つ。各束は「識別子」の行を持ち、決めと提示物はこの識別子で
束を指す。束ねる機能は `product/features.md` にある機能の識別子に限り、半角の `/` で区切る。

このファイルには、パッケージでない節も置いてある。パッケージとして読む節は、設定ファイルの
`[reading.packages]` の `skip_headings` が、読まない見出しを名指しして決める。

- 最終更新: 2026-09-12

- 仮説の状態: 検証中
- 判定根拠: 2026 年に入ってからの引き合い 3 件が、作る前の整理と、決まったことを進める役の不在を挙げていた。受注は 2 件で、どちらも継続している。

- 束ねる機能: requirements-forum / plan-from-decisions / handover-operations
