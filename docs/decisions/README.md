# 設計の決めの記録

この道具の作りについて、後から「なぜこうしたのか」と問われる選択を、決め 1 件につき 1 ファイルで残しています。各ファイルの節は 4 つです。そのとき何が問題だったか（文脈）、何をどうすると決めたか（決め）、捨てた案と捨てた理由（比べた選択肢）、この決めで何が楽になり何を引き受けるか（帰結）。

いまの構造は、リポジトリ直下の `ARCHITECTURE.md` にあります。使い方は、同じくリポジトリ直下の `README.md` です。

## 記録の扱い

- **記録は消しません。** 後の決めに取って代わられたときも、前の記録は書き換えずにそのまま残し、先頭の状態を「取って代わられた」に変えて、どの記録に代わったかを 1 行添えます。決めが変わったこと自体を、読める形で残すためです。
- **新しい決めを足すときは、** このディレクトリにあるファイル名の連番の次を取り、`NNNN-短い題.md`（題は英小文字とハイフン）という名前で作ります。中身は上の 4 節で、先頭に題・状態・日付を置きます。最後に、この一覧へ 1 行足します。
- **1 ファイルは 1〜2 画面で読み切れる長さに保ちます。** 長い解説はこの器ではなく、構造の説明の側に置きます。
- **開発の途中のやり取りは、逐語では書きません。** 残すのは、決めと、その理由と、捨てた案です。誰がいつ何と言ったかの細部は、このリポジトリの外の作業記録に置きます。
