# 書き出し先と媒体の語に、置き場の外へ害が及ぶ道を閉じる守りを置く

- 状態: 採用
- 日付: 2026-10-18

## 文脈

公開した版の作りを自動の安全点検にかけたところ、指摘が 3 件返りました。

- **書き出し先を呼び手が自由に決められる。** 書き出す操作（`export_source`）は、書き出し先が経歴データの置き場の中のときだけ断っていました。提示物の置き場の中を渡すと、正本をつないだ写しが提示物として読まれます。既にあるファイルを渡すと上書きし、symlink を渡すとその先に書き、親ディレクトリが無ければ作っていました。AI のセッションが渡したパスひとつで、置き場の外のファイルを壊せる形です。
- **公開可否を「公開不可」から緩める向きも、操作 1 つで行える。** 点検は、緩める向きには人が確かめる段を挟むべきだと言います。
- **媒体の語の文字を制限していない。** 媒体の語は、提示物の置き場のディレクトリの名前と、媒体ごとの規約のファイルのパスの一部に使われます。語を足す操作（`add_term`）は、空・改行・既にある語だけを断っていたので、`../x` のような語を足すと、提示物の置き場の外のファイルが媒体の規約として読まれます。

## 決め

- **書き出し先は、2 つの置き場の外の、親ディレクトリが既にある新しいファイルに限る。** 提示物の置き場の中は、経歴データの置き場の中と同じ断り（書き出し先は置き場の外）にし、理由に提示物の置き場であることを書きます。既にあるファイル・symlink・親ディレクトリの無い場所は、新しい断り（書き出し先は新しいファイル）にします。symlink は、解決した先がどこでも断ります。上書きを許す引数は足さず、ディレクトリも作りません。書くときは新しいファイルとしてだけ開き、確かめた後に別の手がファイルを置いても上書きしません。次の一手には、別の名前にするか、呼ぶ側が先にファイルを消してから呼び直すことを返します。
- **媒体に足す語は、パスの区切り（`/` と `\`）と制御文字を含まず、`.` で始まらないものに限る。** `.` と `..` もこれに当たります。制約は今までの語の書き方の断りと同じで、理由に何を含んでいたかを書き、媒体のいまの語の一覧を返します。ほかの 5 種類の語はパスに使わないので、文字を狭めません。
- **媒体の規約のファイルと媒体のディレクトリは、パスが提示物の置き場の下に解決されるときだけ読む。** 既にある語彙の語や提示物の宣言に経路の文字が入っていても、置き場の外のファイルは規約として読まず（規約を空として扱う）、置き場の外のディレクトリは提示物を集めるときにたどりません。媒体のディレクトリが置き場の外への symlink のときも同じです。
- **公開可否を緩める向きは、今までどおり 1 つの操作で行う。** 正本の 7 つのファイルのどの変更も accord の操作で行うと決めているので（[0015](0015-close-every-direct-edit-path-with-accord-operations.md)）、人の確かめる段を accord の外に置くと、直接書く道か、操作の無い変更の種類が生まれます。緩める向きを守るのは、書いた後の返り値とコミットの説明に前後の公開可否を載せることです。

## 比べた選択肢

- **書き出し先を、起動の引数で決めた 1 つのディレクトリに固定する。** 点検が挙げた案です。呼び手がパスを選べなくなるので守りは強くなりますが、accord を起動するすべての人の起動の引数が 1 つ増えます。いまの書き出しの使い手は、一時ディレクトリを作り、その中に新しいファイルとして書き出して、読んだら消します。この使い方では、置き場の中と既にあるファイルと symlink を断れば、壊せるものが残りません。そのため採りませんでした。
- **既にあるファイルへの上書きを、引数で許す。** 同じ書き出し先を使い回せて便利ですが、正本の写しが置き場の外に残り続ける使い方を作ります。呼ぶ側が消してから呼び直す手間を引き受けるほうを採りました。
- **語の文字の制限を、語彙の 6 種類すべてに掛ける。** 決まりは 1 つで済みますが、パスに使わない種類の語まで狭めることになり、狭める理由がありません。
- **親ディレクトリが無ければ、今までどおり作る。** 呼び手の手間は減りますが、渡したパスひとつで置き場の外にディレクトリの木ができます。書き出しの使い手は、既にある一時ディレクトリの下に書くので、作らなくても困りません。

## 帰結

書き出す操作と語を足す操作は、呼び手の渡す値がどうであっても、2 つの置き場の外の既にあるファイルを変えず、置き場の外のファイルを規約としても提示物としても読みません。

引き受けるものは 2 つです。

- 同じ書き出し先に繰り返し書き出す人は、毎回先にファイルを消すか、名前を変えます。
- 前の版で `/` や `.` で始まる媒体の語を足していた語彙は、そのまま読めますが、その語の規約のファイルは置き場の外に解決されれば読まれません。直すときは、新しい語を足し、使っている節を直してから、古い語を消します。
