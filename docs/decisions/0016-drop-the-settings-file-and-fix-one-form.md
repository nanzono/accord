# 設定ファイルを廃止し、accord の形を 1 つに固定する

- 状態: 採用
- 日付: 2026-10-14

## 文脈

これまでの accord は、置き場・語彙・正本の読み方（見出しの深さ、欄を箇条書きで書くか表で書くか、欄のラベルの言い方）・書き込みの記録を有効にするか・書き出し先を、経歴データの置き場の中の設定ファイルから読んでいました。読み方を設定に置いたのは、書き方は人によって違い、コードに固定すると別の人の正本が読めなくなると考えたためです。

設定ファイルは、人か AI のセッションが直接書くしかありません。[0015](0015-close-every-direct-edit-path-with-accord-operations.md) で正本の 7 つのファイルを accord の操作だけで変えると決めた後も、置き場の中に「accord を通さずに書くファイル」が 1 つ残っていました。読み方を設定で変えられることは、同じ正本が設定しだいで別の読まれ方をすることでもあり、読み方の鍵を 1 つ書き換えるだけで、型として読む節の範囲が黙って変わります。

## 決め

- **設定ファイルを読まない。** 接続は起動の引数で受けます。`--data` に経歴データの置き場（git の作業ツリーの根）、`--presentations` に提示物と媒体ごとの規約の置き場（省けば提示物 0 件）。書き込みの記録はいつも有効で、書き込み 1 件を 1 件のコミットにし、説明に操作の名前を示す行（`Accord-Operation: <操作の名前>`）を書きます。書き出し先は、書き出す操作が引数で受けます。
- **語彙は置き場の中のデータにする。** 媒体・決めの適用先・機能の分類・パッケージの仮説の状態・公開記録の種類・公開記録の役割の 6 種を、置き場の `vocabulary.md` から読みます。
- **accord の形を 1 つに固定する。** 2026-10-14 時点で実際に使っている経歴データの書き方（7 つのファイルの名前と置き場、見出しの深さ、欄の書き方、欄のラベルの読み替え、読み飛ばす節、媒体ごとの規約のファイル、禁じた言い回しの表）を、accord の唯一の形としてコードの定数に固定します。読み方を変える設定も引数も受けません。形の全体と、コードが名前で使う語の一覧は [docs/data-format.md](../data-format.md) 1 か所に書き、見本（`samples/data/` と `samples/presentations/`）をその実例にします。違う書き方の正本を持つ人は、移行の操作で accord の形に変換します。
- **形を決める名前と中身を分ける。** コードが名前で使う語は、data-format.md の一覧に挙げたものだけにします。パッケージ定義で読み飛ばす覚え書きの節は、見出しの名前で指さず、パッケージの型の欄を 1 つも持たない節として見分けます。見出しの名前で指すと、利用者のデータの中身がコードに入るためです。

## 比べた選択肢

- **設定ファイルを残し、accord の操作で書き換えさせる。** 設定を書き換える操作を足せば直接書く道は閉じますが、読み方を変えられること自体が残り、同じ正本の読まれ方が設定しだいで変わります。
- **第 1 版の書き方へ経歴データを変換する。** 同梱の第 1 版の見本の書き方（職歴の枠と受託案件を別のファイルに置き、欄のラベルを読み替えない形）を唯一の形にし、実際の経歴データをその形に変換する案です。経歴の正本の職歴の節の多くで、いま同じ値を 3 つの欄に読ませている「期間 / 所属・立場」の欄が、変換すると同じ値の 3 行に重なり、人が読む文として悪くなります。7 つのファイルの本文を大きく書き換えるので、中身を壊す危険も大きくなります。いま使っている書き方を形として固定すれば、本文を 1 文字も変えずに済みます。
- **パッケージ定義の読み飛ばしを「欄を 1 つも持たない節」にする。** 実際の経歴データの覚え書きの節は、型に無い欄を 1 つ持っているので、この決まりでは読み飛ばされず、パッケージとして読む節が増えます。「ID の欄を持たない節」にすると、ID を書き忘れたパッケージが黙って読み飛ばされます。「型の欄を 1 つも持たない節」なら、どちらも起きません。

## 帰結

置き場の中には、accord の 7 つの正本のファイルと `vocabulary.md` だけが残り、どれも accord の操作で書く対象になります。正本の読まれ方は 1 通りで、設定の書き違いで読む範囲が変わることはありません。

引き受けるものは 3 つです。

- 書き方の違う正本を持つ人は、そのままでは accord を使えません。移行の操作で accord の形に変換してから使います。
- 経歴データの置き場は git の作業ツリーの根でなければ起動しません。
- 同梱の見本は 1 つになり、第 1 版の書き方の見本は消しました。読み方の鍵を 1 つずつ確かめていた要件とテストは、accord の形の要件に取って代わられました。
