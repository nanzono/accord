# 文面そのものを作らせない

- 状態: 採用
- 日付: 2026-09-15

## 文脈

職務経歴書やプロフィールの文章を書く仕事には、判断と文章力が要ります。出来上がりの良し悪しは、機械では判定できません。

道具がそこまで引き受けると、返ってくる答えに「たぶん」が混ざります。検査の結果に主観が混ざると、読み手はどの指摘を信じてよいか分からなくなり、結局どの指摘も効かなくなります。

## 決め

accord が引き受けるのは、機械で白黒の付く一致だけです。文面は作りません。

返すのは 2 つです。文章を書くための材料（いま前面に出しているもの、その説明、根拠になる実績の本文、媒体の書き方の決まり、使わないと決めた言い回し）と、正本との食い違いの指摘です。指摘には、どのファイルのどこを、何に合わせるかまで書きます。

文章を書くのは、人か AI の仕事のままにしてあります。

## 比べた選択肢

- **文面の下書きまで作る。** 良し悪しを機械で判定できないので、検査の結果に主観が混ざります。
- **言い回しの良し悪しも検査に含める。** 同じ理由で、守るものの線が引けなくなります。
- **材料は渡さず、検査だけする。** 文面を書く瞬間に正本を開き直すことになり、決まりを思い出せないという最初の問題が残ります。

## 帰結

返ってくる答えが確定します。「この文面はこのパッケージを名乗っているが、いまの決めは別のパッケージを前面に出している」のように、断定できることだけを言います。守る線と守らない線を、利用者に一言で説明できます。

引き受けるものは、これがよい職務経歴書を書くための道具ではない、という事実です。文章の質は、この道具の外で書き手が引き受けます。
